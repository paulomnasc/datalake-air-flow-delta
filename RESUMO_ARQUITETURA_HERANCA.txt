🏗️ ARQUITETURA
─────────────────────────────────────────────────────────────────────────────

RawToMedallionPipeline.__call__()
    ├─ 1. _setup()                      ← Inicializa
    ├─ 2. _process_bronze()             ← Bronze Layer
    ├─ 3. _process_silver()             ← Silver Layer
    │   ├─ bronze_to_silver()           (padrão)
    │   └─ silver_layer_transform()     ← HOOK (customize aqui!)
    ├─ 4. _process_gold()               ← Gold Layer
    │   ├─ silver_to_gold()             (padrão)
    │   └─ gold_layer_transform()       ← HOOK (customize aqui!)
    ├─ 5. _process_delta()              ← Delta Layer
    └─ 6. _cleanup()                    ← Limpeza

Cada etapa espera a anterior terminar → SINCRONIZAÇÃO GARANTIDA

OPÇÃO 2: Novo padrão (RECOMENDADO)
────────────────────────────────────
from lib.medallion_pipeline_v2 import RawToMedallionPipeline

class MeuValidador(RawToMedallionPipeline):
    def silver_layer_transform(self, silver_key: str) -> str:
        # Sua lógica customizada
        return silver_key

pipeline = MeuValidador()
result = pipeline(
    source_filename='raw/dados/tabela.csv',
    target_table_name='tabela'
)

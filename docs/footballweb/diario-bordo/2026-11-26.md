## 1. Controle Dinâmico do Modo Operacional Cloudbet (Dry-Run / Real) via Cache MySQL e Interface Web

### 1.1 Motivação e Diagnóstico Técnico
- Anteriormente, a alteração entre Modo Simulação (Paper Trading) e Modo Real (Dinheiro Real em USDT) dependia exclusivamente da edição manual do arquivo `.env` (`CLOUDBET_DRY_RUN=true/false`).
- Essa dependência de arquivos em disco gerava três problemas de arquitetura:
  1. **Inviabilidade de Gestão via Web**: O container Docker da aplicação web roda com privilégios restritos (`www-data`) e não deve ter permissão de escrita arbitrária em arquivos do host Linux por segurança.
  2. **Risco de Dessincronia**: A existência de múltiplos arquivos `.env` (na raiz do repositório para o Airflow e em `src/footballweb/` para a web) podia levar a estados contraditórios.
  3. **Falta de Visibilidade Operacional Instantânea**: O usuário desenvolvedor não possuía um sinalizador no topo da tela informando se o robô estava apostando em dinheiro real ou em simulação.

### 1.2 Abordagem Técnica e Arquitetura Implementada
- **Hierarquia Soberana com Fallback Fail-Safe**:
  1. **Prioridade 1 (Soberana - Tempo Real)**: Banco de dados MySQL / Cache (`metas_diarias_config.cloudbet_dry_run`). O que o usuário configurar na interface web passa a valer imediatamente no próximo ciclo do robô Python.
  2. **Prioridade 2 (Fallback Fail-Safe - Disjuntor de Proteção)**: Se o banco estiver fora do ar ou o registro for nulo, recorre ao arquivo `.env` (`CLOUDBET_DRY_RUN=true`). Isso garante que o sistema **nunca aposte dinheiro real por acidente em caso de pane**.
- **Convenção Visual da Opção B (Sinalizador Luminoso no Header)**:
  - 🟢 **Sinal Verde**: `CLOUDBET_DRY_RUN=false` (Operação Real Ativa com saldo USDT).
  - 🔴 **Sinal Vermelho**: `CLOUDBET_DRY_RUN=true` (Modo Simulação / Operação Real Desativada).
- **Segregação de Responsabilidade (UX)**:
  - **No Header (`header.php`)**: Fica exclusivamente a **Label Visual Informativa** com ponto luminoso pulsante (verde ou vermelho), visível em todas as páginas, com link direto para Metas.
  - **Na Tela de Metas (`metas/index.php`)**: Fica o **Botão Toggle Interativo** no modal de configuração de parâmetros, posicionado estrategicamente ao lado da `stake_padrao` e da conversão de moeda, incluindo confirmação explícita de segurança antes de mudar para Dinheiro Real.

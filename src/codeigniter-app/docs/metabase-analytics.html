Guia de Uso: Metabase Analytics

Aprenda a acessar, explorar e criar dashboards de BI interativos no Metabase com isolamento de dados por inquilino

Visão Geral

O MyDataFlow integra o Metabase como sua ferramenta nativa de Business Intelligence (BI) e visualização de dados. A integração foi projetada sob uma arquitetura multi-inquilino (multi-tenant) robusta e segura, operando com total transparência e zero burocracia para o usuário final.

Pilares da Arquitetura de Segurança

  • SSO Silencioso (Single Sign-On): O login no Metabase ocorre automaticamente ao clicar no painel. O backend gera um token JWT assinado digitalmente, autenticando você instantaneamente sem pedir usuário ou senha adicionais.
  • Isolamento Físico de Schemas: Suas consultas no Metabase conectam-se ao banco de dados PostgreSQL analítico (postgres-bi) utilizando uma role restrita a nível de banco (user_aluno_{id}), com permissão exclusiva de leitura (SELECT) apenas sobre o seu schema de produção user_{id}_analytics.

Pré-Requisitos

Para garantir que o Metabase exiba seus dados corretamente ao fazer o primeiro acesso, você deve materializá-los a partir de seus pipelines de transformação:

  • 1

    Materializar dados em Produção

    Abra o menu Serviços → SQL Editor + Customizações Python, selecione a aba **📊 dbt Analytics** e execute o comando **▶️ dbt Run (Prod)**.

    Esse comando compila seus modelos SQL e gera as tabelas físicas na camada final (Gold) no schema de produção user_{id}_analytics.

  • 2

    Tratamento de Base de Dados Vazia

    Se o seu schema de produção não possuir nenhuma tabela estruturada (base limpa ou recém-criada), o dashboard do MyDataFlow exibirá um aviso chamativo instruindo-o a rodar o dbt.

    O botão "Meu Analytics" permanecerá inativo ou exibirá o alerta para evitar que você seja redirecionado para um painel em branco no Metabase.

Como Acessar o Metabase

Siga o passo a passo abaixo para acessar e iniciar suas análises:

  • 1

    Acessar o Painel Principal

    No dashboard principal do MyDataFlow, localize a seção de atalhos rápidos ou o menu correspondente ao Analytics.

  • 2

    Clicar em "Meu Analytics"

    Clique no botão Meu Analytics. A plataforma fará o provisionamento automático em tempo real:

    • Criará a role exclusiva de banco de dados user_aluno_{id} com permissão SELECT.
    • Garantirá que o Metabase possua um banco cadastrado apontando diretamente para o seu schema.
    • Criará seu usuário do Metabase com permissões isoladas para o seu banco.
  • 3

    Redirecionamento Automático

    O navegador será redirecionado de forma segura e transparente para a URL externa do Metabase (http://myflow.estudotabela.com.br:28300) utilizando a credencial gerada por JWT.

Explorando Dados e Criando Perguntas

Dentro do Metabase, você tem a liberdade de explorar dados de forma visual ou via query SQL tradicional:

  • 1

    Selecionar Base de Dados

    Na página inicial do Metabase, localize e clique sobre a base de dados com o seu identificador de inquilino (ex: DW - User {id}).

  • 2

    Criar uma Pergunta Visual (Question)

    Clique em + New (Novo) no canto superior direito e selecione Question (Pergunta). Escolha o banco correspondente e a tabela de interesse (ex: fato_vendas). Utilize a interface intuitiva para aplicar filtros, resumir (somas, médias, contagens) e agrupar por campos.

  • 3

    Escrever Consultas SQL Customizadas

    Se preferir, clique em + New → SQL Query. Selecione o banco de dados associado e escreva consultas de agregação de alta complexidade. Exemplo:

    SELECT 
    v.categoria, 
    SUM(v.valor_total) AS faturamento,
    COUNT(DISTINCT v.cliente_id) AS total_clientes
FROM fato_vendas v
GROUP BY v.categoria
ORDER BY faturamento DESC

Criando Dashboards Completos

Combine múltiplas visualizações e cartões KPI em um dashboard consolidado para monitoramento:

  • 1

    Criar Painel Vazio

    Clique em + New → Dashboard. Atribua um nome explicativo (ex: Indicadores de Vendas e Cadastro) e clique em Create.

  • 2

    Adicionar Visualizações

    Dentro do dashboard, clique no ícone de Adicionar Pergunta (ícone de gráfico com "+") no topo direito e insira as perguntas que você salvou anteriormente.

  • 3

    Configurar Filtros de Painel

    Adicione filtros interativos ao topo do dashboard (ex: Filtro de Datas ou Categorias) e mapeie quais colunas de quais cartões devem obedecer a esses filtros dinâmicos.

  • 4

    Salvar e Compartilhar

    Salve a disposição do seu dashboard. Ele será atualizado de forma síncrona sempre que novos dados forem ingeridos e processados pelo dbt Run.

Integração com o Controle de Assinaturas

O ciclo de vida do seu usuário e suas permissões no ecossistema de BI está integrado de forma síncrona ao controle de assinaturas da plataforma MyDataFlow:

Assinatura Ativa (Regularizada)

Usuário e banco permanecem ativos no Metabase. A role de banco do PostgreSQL user_aluno_{id} tem permissão irrestrita de login (LOGIN) e leitura no schema de produção.

Assinatura Inativa ou Suspensa

O sistema revoga automaticamente a permissão de login no banco de dados analítico (ALTER ROLE user_aluno_{id} NOLOGIN). Simultaneamente, o usuário correspondente no Metabase é inativado (active = false) por meio da API do Metabase, bloqueando qualquer nova visualização ou acesso via SSO.

Reativação Automática

Quando a assinatura volta a ficar ativa, o backend restaura imediatamente os privilégios de login do PostgreSQL (LOGIN) e reativa o usuário no Metabase (active = true). Todos os seus dashboards e cartões criados anteriormente são totalmente preservados.

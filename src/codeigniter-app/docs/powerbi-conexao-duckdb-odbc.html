Power BI + DuckDB (via ODBC)

Siga os passos para conectar o Power BI ao seu Datalake utilizando as credenciais definidas.

👉 Documentação Oficial DuckDB (ODBC)

Como instalar:

  • 1. Extraia o ZIP e localize o arquivo duckdb_odbc.inf.
  • 2. Clique com o botão direito e selecione Instalar.

2. Configurar Fonte de Dados (DSN)

  1. No Windows, abra Fontes de Dados ODBC (64 bits).
  2. Em DSN de Sistema, clique em Adicionar e selecione DuckDB Driver.
  3. Configure os campos conforme abaixo:
DSN Name: DuckDB_Datalake
Database: C:\caminho\datalake_airflow.duckdb
Custom Strategy: postgres (se disponível)

3. Conectar no Power BI

  1. Vá em Obter Dados > ODBC e selecione DuckDB_Datalake.
  2. Clique em Opções Avançadas e insira a consulta SQL:
select * from public.delta_artist;
  1. Credenciais de Acesso: Quando a janela de autenticação abrir, selecione a aba Banco de Dados e informe:
Usuário: pbi_user
Senha: pbi_password
Banco (Database): datalake_bi

* Essas credenciais garantem a compatibilidade com o schema definido no seu ambiente de dados.

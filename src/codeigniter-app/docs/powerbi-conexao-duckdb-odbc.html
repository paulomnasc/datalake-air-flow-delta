🔗 Conexão Power BI Desktop ao PostgreSQL Datalake BI

Este guia mostra como conectar o Power BI Desktop diretamente ao banco de dados PostgreSQL do Datalake.

✅ Vantagens desta abordagem:
• Conexão direta ao banco de dados
• Múltiplas conexões simultâneas
• Melhor performance
• Suporta DirectQuery para dados em tempo real
• Integração nativa com Power BI

1. Configurar Conexão PostgreSQL

  1. Abra o Power BI Desktop
  2. Vá em Obter Dados > Banco de Dados > Banco de Dados PostgreSQL
  3. Na janela de conexão, preencha:
Servidor: 46.224.156.251:25433
Banco de dados: datalake_bi
⚠️ Importante: Substitua SEU_HOST_REMOTO pelo IP ou hostname do seu servidor PostgreSQL.
Exemplos: 46.224.156.251:25433 ou meuservidor.com:25433
Se estiver na mesma máquina: localhost:25433

2. Configurar Autenticação

Resolver Erro de SSL/Criptografia

Se aparecer erro relacionado a SSL ou criptografia, clique em Opções Avançadas e desabilite o SSL.

Credenciais de Acesso

Na janela de autenticação, selecione a aba Banco de Dados e insira:

Banco de Dados: datalake_bi
Nome de usuário: pbi_user
Senha: pbi_password

Clique em Conectar

3. Selecionar Tabelas

Após conectar, você verá a lista de tabelas disponíveis no schema public:

  • delta_artist
  • delta_invoice
  • delta_employee
  • delta_customer
  • ... e outras tabelas disponíveis

Selecione as tabelas que deseja importar ou consultar.

4. Escolher Modo de Conectividade

Antes de carregar os dados, escolha entre Import ou DirectQuery:

📊 Import (Importar - Padrão)

Quando usar:

  • ✅ Dashboards e relatórios com dados que não mudam constantemente
  • ✅ Quando precisa de melhor performance nas visualizações
  • ✅ Quando usa muitas funções DAX complexas
  • ✅ Para trabalhar offline

Características:

  • ✅ Melhor performance nas visualizações
  • ✅ Funciona offline
  • ✅ Todos os recursos DAX disponíveis
  • ❌ Precisa atualizar manualmente para ver novos dados
  • ❌ Consome memória local (dados são copiados)

⚡ DirectQuery (Consulta Direta)

Quando usar:

  • ✅ Dados que mudam frequentemente e precisam estar sempre atualizados
  • ✅ Volumes muito grandes de dados (GB/TB)
  • ✅ Quando não pode copiar dados por questões de governança
  • ✅ Para dashboards em tempo real

Características:

  • ✅ Sempre mostra dados atualizados em tempo real
  • ✅ Não consome memória local (dados ficam no servidor)
  • ✅ Ideal para grandes volumes de dados
  • ❌ Mais lento (cada visualização faz query no banco)
  • ❌ Requer conexão constante com o servidor
  • ❌ Algumas funções DAX não funcionam
💡 Recomendação:
• Use Import para desenvolvimento, testes e dashboards pequenos/médios
• Use DirectQuery para dados que mudam frequentemente ou volumes muito grandes
• Você pode combinar ambos em um mesmo relatório (modo Composite)

Como Escolher:

  1. Após selecionar as tabelas, clique em Carregar (para Import) ou OK (aparecerá opção para DirectQuery)
  2. Para mudar o modo depois, vá em Modelagem > Configurações de modelo

✅ Pronto!

Agora você está conectado ao Datalake BI e pode:

  • Criar relacionamentos entre tabelas
  • Criar medidas DAX
  • Construir visualizações
  • Publicar no Power BI Service (se usar Import)
